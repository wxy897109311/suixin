# 随手账（PWA 手机 App 版）V0.3

在原「随手账 V0.2」记账网页基础上，升级为 **PWA（渐进式网页应用）**：
手机上可以像原生 App 一样 **安装到桌面、全屏运行、离线记账**，无需应用商店。

## 文件说明

| 文件 | 作用 |
| --- | --- |
| `随手账-V0.2.html` | App 本体（已加入 PWA 能力：清单、安装引导、离线缓存、刘海屏适配） |
| `manifest.webmanifest` | PWA 清单：名称、图标、主题色、全屏模式 |
| `sw.js` | Service Worker：离线缓存与自动更新 |
| `icons/` | App 图标（192 / 512 / 掩码图标 / iOS 180） |
| `server.js` | 本地预览服务器（Node 内置，无需安装依赖） |
| `test-core.js` | 核心记账逻辑冒烟测试 |

## 在手机上安装使用

> 注意：**正式安装（PWA）要求 HTTPS 或 localhost**。浏览器里直接打开也可正常使用（只是不能离线/安装）。

### 方式一：免费托管到 HTTPS（推荐，人人可装）
把整个文件夹上传到任一静态托管（免费）：
- **GitHub Pages**：新建仓库 → Settings → Pages → 部署分支
- **Netlify / Vercel**：直接拖拽文件夹上传

然后用手机浏览器打开托管网址，即可安装。

### 方式二：本机局域网测试（电脑 + 手机同一 WiFi）
```bash
node server.js        # 默认端口 8080
```
- 电脑浏览器打开 `http://localhost:8080`
- 手机浏览器打开 `http://<电脑IP>:8080`（如 `http://192.168.1.5:8080`）
- 局域网 HTTP 下功能全部可用，但 Service Worker（离线/安装）仅在 localhost 生效

### 安装步骤
- **Android（Chrome / Edge）**：打开网页 → 会自动弹出「安装」引导条；也可点右上角菜单 → 「添加到主屏幕 / 安装应用」
- **iPhone / iPad（Safari）**：点分享按钮 → 「添加到主屏幕」→ 桌面出现 App 图标，全屏打开

## 功能说明
- **一句话记账**：输入「昨天买菜86，晚上吃饭128，支付宝付的」→ 自动识别多笔收支 → 确认后入账
- **语音记账**：点 🎙️ 说话（Android 的 Chrome/Edge 支持；iOS Safari 不支持语音，需文字输入）
- 账单管理：搜索 / 筛选 / 编辑 / 删除
- 月度分析：收入、支出、分类统计
- 数据只保存在本机浏览器（localStorage），不上传服务器，清空数据在「设置」页
